# لیست ایشوها و بدهی‌های فنی (Issues & Technical Debt)

این سند برای ردیابی مواردی است که نیاز به اصلاح یا بهبود دارند اما در اولویت لحظه‌ای نیستند.

## بدهی‌های فنی (Technical Debt)
- [x] **Hardcoded Room:** سیستم اتاق‌های پویا و لابی پیاده‌سازی شد. (DONE)
- [x] **Memory Persistence:** وضعیت بازی‌ها اکنون در SQLite ذخیره می‌شود. (DONE)
- [ ] **Socket Identity:** سوکت‌ها هنوز به طور کامل با هویت JWT بازیکنان گره نخورده‌اند (فعلاً از socket.id استفاده می‌شود).
- [ ] **Scaling:** برای مقیاس‌پذیری و توزیع سوکت‌ها بین چندین سرور نیاز به Redis داریم.
- [ ] **Error Handling:** مدیریت خطا در Gateway سرور هنوز ابتدایی است.

## باگ‌های شناخته شده
- [x] مشکل رفرش صفحه وب و قطع اتصال (با استفاده از RoomService و دیتابیس تا حد زیادی مرتفع شد، اما نیاز به Reconnect logic در کلاینت دارد).
- [ ] انجین فعلی حرکت‌های تکراری در یک خانه دوز را در سمت سرور به درستی بلاک نمی‌کند (فقط در کلاینت بلاک می‌شود).

## پیشنهادات بهبود
- [ ] اضافه کردن سیستم **Undo** برای بازی‌های دونفره.
- [ ] پیاده‌سازی سیستم **Timer** برای هر نوبت جهت جلوگیری از معطلی بازیکنان.
- [ ] استفاده از **Zod** برای اعتبارسنجی پیام‌های ورودی به سوکت.
