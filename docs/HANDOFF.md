# مستند هندآف (Hand-off) پروژه BaziGB

تاریخ: ۱۶ مرداد ۱۴۰۵
وضعیت پروژه: بچ ۴ تکمیل شد - شطرنج آنلاین عملیاتی است

## وضعیت فعلی
پلتفرم BaziGB اکنون از چندین بازی به صورت همزمان پشتیبانی می‌کند. دومین بازی بزرگ (شطرنج) به همراه رابط کاربری حرفه‌ای و منطق کامل به سیستم اضافه شد.
- **Engine Core:** ارتقا یافته برای پشتیبانی از چندین نوع پلاگین بازی.
- **Chess Plugin:** پیاده‌سازی کامل با استفاده از `chess.js` شامل مدیریت FEN و اعتبارسنجی حرکت‌ها.
- **Multi-game Gateway:** سرور اکنون می‌تواند بر اساس `gameType` اتاق، منطق درست را بارگذاری کند.
- **Chess UI:** استفاده از `react-chessboard` برای نمایش بصری و کشیدن و رها کردن مهره‌ها.
- **Lobby Integration:** امکان انتخاب نوع بازی (دوز یا شطرنج) در زمان ساخت اتاق.

## کارهای انجام شده
- [x] ایجاد پکیج `@bazigb/game-chess` و پیاده‌سازی منطق استاندارد شطرنج.
- [x] ریفاکتور `GameGateway` برای پشتیبانی از بارگذاری داینامیک بازی‌ها.
- [x] پیاده‌سازی کامپوننت `ChessBoard` در اپلیکیشن وب.
- [x] اضافه کردن قابلیت انتخاب بازی در لابی.
- [x] ثبت صحیح نوع بازی در تاریخچه مسابقات.

## گام‌های بعدی پیشنهادی
۱. **سیستم رنکینگ (ELO):** محاسبه امتیاز بازیکنان بر اساس نتایج مسابقات (فاز ۴ نقشه راه).
۲. **Spectator Mode:** امکان تماشای بازی‌های در حال جریان.
۳. **بهبود رابط کاربری شطرنج:** نمایش لیست حرکت‌ها (PGN) و مهره‌های خارج شده.
۴. **صدا و انیمیشن:** اضافه کردن جلوه‌های صوتی برای حرکت مهره‌ها.
۵. **مهاجرت به Postgres:** جایگزینی SQLite برای محیط Production.

## پروتکل عملیاتی BaziGB (مهم برای هوش مصنوعی)

برای حفظ نظم و جلوگیری از شلوغی Context، تمام تسک‌ها باید طبق این پروتکل انجام شوند:

۱. **دسته بندی (Batching):** تسک‌ها بر اساس نقشه راه (Roadmap) به گروه‌های حداکثر ۵تایی تقسیم می‌شوند.
۲. **برون‌سپاری (Delegation):** انجام تسک‌ها به ساب‌ایجنت‌ها (`sessions_spawn`) سپرده می‌شود. هر ساب‌ایجنت مسئول یک خروجی مشخص و مستقل است.
۳. **تأیید و ادغام (Verify & Merge):** پس از اتمام کار ساب‌ایجنت‌ها، ایجنت اصلی نتایج را وریفای کرده و با کد اصلی مرج می‌کند.
۴. **بروزرسانی مستندات:** پس از هر بچ، تمام مستندات فنی و فایل `HANDOFF.md` بر اساس تغییرات جدید آپدیت می‌شوند.
۵. **ثبت نهایی (Push):** پس از تأیید نهایی هر بچ ۵تایی، کدها به مخزن GitHub پوش می‌شوند.

## نکات فنی برای توسعه‌دهنده بعدی
- برای اجرای کل پروژه، در ریشه دستور `npm install` را بزنید.
- منطق بازی‌ها را فقط در `packages/games` تغییر دهید.
- انجین در حال حاضر بسیار ساده است و نیاز به سیستم `Undo` و `Redo` دارد.
