# نقشه راه BaziGB (Roadmap)

این سند مسیر توسعه پلتفرم **BaziGB** را ترسیم می‌کند. وضعیت دقیق هر بچ در [HANDOFF.md](HANDOFF.md) است.

## فاز ۱: زیرساخت هسته و اثبات مفهوم (تکمیل ✅)
- [x] راه‌اندازی ساختار Monorepo.
- [x] طراحی انجین بازی‌های نوبتی (Turn-based Engine).
- [x] پیاده‌سازی سرور Socket.io برای همگام‌سازی وضعیت.
- [x] پیاده‌سازی اولین بازی (دوز - Tic Tac Toe).
- [x] راه‌اندازی CI پایه در GitHub.

## فاز ۲: پایداری و مدیریت کاربران (تکمیل ✅)
- [x] Persistence: دیتابیس (PostgreSQL در پروداکشن، Prisma).
- [x] Authentication: ثبت‌نام و ورود (ایمیل + شماره موبایل/OTP).
- [x] Lobby UI: ساخت اتاق و پیوستن با کد دعوت.
- [x] Profiles UI: آمار برد و باخت.

## فاز ۳: گسترش کاتالوگ بازی‌ها (در حال اجرا 🔄)
- [x] شطرنج (Chess) با رابط کاربری اختصاصی.
- [x] تخته‌نرد (Backgammon) با سیستم تاس و بورد بازطراحی‌شده (بچ ۱۸/۱۹).
- [x] زیرساخت صوتی (SFX) با کنترل از هدر.
- [x] وگاس (Vegas) — کارت‌های پول ۵۴تایی، ۴ راند، قانون ۸ تاس (بچ ۱۰).
- [ ] بازی‌های کلاسیک اضافه (منچ، ماروپله و…) — از [GAME_SDK.md](GAME_SDK.md) پیروی کنید.
- [x] **VS Computer (پایه):** AI دوز + تخته‌نرد با ۳ سطح دشواری (بچ ۱۸–۱۹)؛ شطرنج/وگاس در دست توسعه.

## فاز ۴: قابلیت‌های اجتماعی و رقابتی (تکمیل ✅)
- [x] Ranking: سیستم امتیازدهی ELO.
- [x] Spectator Mode: تماشای بازی‌های فعال.
- [x] Chat & Social: چت زنده داخل اتاق + پیام‌های سیستم.
- [x] Tournament Engine: مسابقات حذفی و دوره‌ای.
- [x] Leaderboard: برترین‌ها در لابی و صفحه اختصاصی.
- [x] OTP Login: ورود/ثبت‌نام با موبایل از طریق sms.ir (بچ ۱۴).
- [x] Admin Panel: RBAC + داشبورد (آمار، مدیریت کامل کاربران) (بچ‌های ۱۴–۱۶).
- [x] Match Settings: مسابقات «Best of 3/5» با پیگیری امتیاز راندها (بچ ۱۸).

## فاز ۵: اکوسیستم و مقیاس‌پذیری (در حال اجرا 🔄)
- [ ] Notifications: اعلان لحظه‌ای برای شروع نوبت و مسابقات.
- [ ] Plugin SDK: نهایی‌کردن SDK برای توسعه‌دهندگان شخص ثالث.
- [ ] Mobile App: پکیج‌کردن فرانت‌اند برای Android/iOS.
- [ ] Global Scaling: Redis برای توزیع وضعیت بازی بین چند سرور.
- [ ] AI کامل‌تر: هوش مصنوعی شطرنج (موتور) و وگاس با لول‌بندی.

## فاز ۶: UI/UX، برند و دیزاین سیستم (تکمیل ✅)
- [x] اتو-لیوت مشترک: AppShell با sticky header و فوتر.
- [x] فوتر داینامیک قابل ویرایش از پنل ادمین (مدل SiteSetting).
- [x] ریسپانسیو کامل 360/768/1440 + حذف گرادیان‌ها (بچ ۱۵-ب) + ممیزی مجدد و فیکس هدر/لیدربورد/صفحه بازی (بچ ۱۷).
- [x] ممیزی UX با ۱۰ هیوریستیک نیلسن — موارد فوری فیکس، شکاف‌ها در ISSUES.md (بچ ۱۷).
- [x] پالت برند اولیه: Autumn Ember / Dark Teal (بچ ۱۵).
- [x] یکدست‌سازی نام برند: BaziG3 → BaziGB.
- [x] لوگوی رسمی ترنسپرنت در هدر/hero/auth/فوتر/favicon.
- [x] **DESIGN_SYSTEM.md (قانون اساسی):** پالت جدید Honey Bronze `#EEAC2F` / Prussian Blue `#061A2D` / Ink Black `#030A15` / Dark Coffee `#392E24`، فونت Vazirmatn، میکرواینترکشن‌ها، ریسپانسیو و a11y — **اجرای سراسری (بچ ۱۹) در حال تکمیل است**.
- [x] نماد اعتماد اینماد در فوتر (بچ ۱۸).

## فاز ۴.۵ — بدهی‌های فنی (تکمیل ✅)
- [x] تغییر رمز کاربران: `PATCH /auth/change-password` (بچ ۱۵-ب).
- [x] هویت سوکت با JWT (بچ ۱۵-ب).
- [x] تایمر نوبت ۱۲۰ ثانیه با end-turn خودکار (بچ ۱۵-ب).
- [x] مدیریت کامل کاربران ادمین: ریست آمار، غیرفعال‌سازی، حذف کامل، ویرایش (بچ ۱۶).
- [x] اعتبارسنجی Zod پیام‌های سوکت (بچ ۱۶).
- [x] فیکس باگ دوز (حرکت تکراری) (بچ ۱۶).
- [x] هوشمندسازی تخته‌نرد: Move Hints، حرکات خودکار اجباری، اتوماسیون bearing-off (بچ ۱۸).
- [x] بازطراحی بصری بورد تخته‌نرد: SVG + بافت چوب/چرم + مهره‌های ۳بعدی + Framer Motion (بچ ۱۸–۱۹).

## بدهی‌های باز (برای بچ‌های آینده)
- AI شطرنج و وگاس (لول‌بندی).
- راهنمای قوانین بازی‌ها داخل اپ (هیوریستیک ۱۰).
- یکدست‌سازی زبان لیبل‌ها (فارسی/انگلیسی).
- رفع صدای تاس هنگام ریختن همزمان دو بازیکن.
- Redis/Scaling، کلید SSH دیپلوی، Postgres لوکال، تصمیم لوگوی BaziG3 (جزییات: [ISSUES.md](ISSUES.md)).
