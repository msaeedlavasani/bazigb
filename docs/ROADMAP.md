# نقشه راه BaziGB (Roadmap)

این سند مسیر توسعه پلتفرم **BaziGB** را در ۶ فاز اصلی ترسیم می‌کند.

## فاز ۱: زیرساخت هسته و اثبات مفهوم (تکمیل شده ✅)
- [x] راه‌اندازی ساختار Monorepo.
- [x] طراحی انجین بازی‌های نوبتی (Turn-based Engine).
- [x] پیاده‌سازی سرور Socket.io برای همگام‌سازی وضعیت.
- [x] پیاده‌سازی اولین بازی (دوز - Tic Tac Toe).
- [x] راه‌اندازی CI/CD اولیه در GitHub.

## فاز ۲: پایداری و مدیریت کاربران (تکمیل شده ✅)
- [x] **Persistence:** اضافه کردن SQLite و Prisma برای ذخیره دائم اطلاعات.
- [x] **Authentication:** سیستم ثبت‌نام و ورود (سمت سرور و وب).
- [x] **Lobby UI:** رابط کاربری انتخاب اتاق و ساخت اتاق با کد دعوت.
- [x] **Profiles UI:** نمایش آمار برد و باخت در فرانت‌اِند.

## فاز ۳: گسترش کاتالوگ بازی‌ها (در حال اجرا 🔄)
- [x] **Chess:** پیاده‌سازی شطرنج به همراه رابط کاربری حرفه‌ای.
- [x] **Backgammon:** اضافه کردن بازی تخته‌نرد و سیستم تاس.
- [x] **Asset Pipeline:** پیاده‌سازی سیستم مدیریت صدا و افکت‌های صوتی (SFX).
- [x] **Vegas:** پیاده‌سازی بازی استراتژیک تاس‌محور وگاس.
- [ ] **Classic Pack:** اضافه کردن بازی‌های ساده‌تر مثل منچ و ماروپله.

## فاز ۴: قابلیت‌های اجتماعی و رقابتی (تکمیل شده ✅)
- [x] **Ranking System:** پیاده‌سازی سیستم امتیازدهی ELO.
- [x] **Spectator Mode:** امکان تماشای بازی‌های فعال به صورت زنده.
- [x] **Chat & Social:** چت زنده داخل اتاق و پیام‌های سیستم.
- [x] **Tournament Engine:** زیرساخت برگزاری مسابقات حذفی و دوره‌ای.
- [x] **Leaderboard:** نمایش برترین‌ها در لابی و صفحه اختصاصی.
- [x] **OTP Login:** ورود/ثبت‌نام با شماره موبایل از طریق پیامک (sms.ir) — بچ ۱۴.
- [x] **Admin Panel (پایه):** زیرساخت RBAC (نقش + گارد) و داشبورد مدیریتی اولیه با آمار و لیست کاربران — بچ ۱۴.

## فاز ۵: اکوسیستم و مقیاس‌پذیری (در حال اجرا 🔄)
- [ ] **Notifications:** سیستم اعلان لحظه‌ای برای شروع نوبت و مسابقات.
- [ ] **Plugin SDK:** نهایی کردن SDK برای توسعه‌دهندگان شخص ثالث.
- [ ] **Mobile App:** پکیج کردن فرانت‌اِند برای Android و iOS.
- [ ] **Global Scaling:** استفاده از Redis برای توزیع وضعیت بازی بین چندین سرور.

## فاز ۶: UI/UX و برند (بچهای ۱۵ و ۱۵-ب — تکمیل شده ✅)
- [x] **اتو-لیوت مشترک:** ساختار واحد هدر/محتوا/فوتر (AppShell با sticky footer).
- [x] **هدر هماهنگ:** اصلاح Nav برای اتو-لیوت و هم‌ترازی با کانتینر صفحات.
- [x] **فوتر + ویرایش ادمین:** فوتر با محتوای قابل ویرایش از پنل ادمین (مدل SiteSettings).
- [x] **ریسپانسیو:** بررسی و اصلاح تمام صفحات در 360/768/1440 + **حذف کامل گرادیان‌ها** (رنگ‌های توپر پالت) — بچ ۱۵-ب.
- [x] **پالت رنگی برند:** Autumn Ember `#B25D16`، Dark Teal `#114B5E`، Orange `#F5A306`، Ash Grey `#BEBBAC`، Ink Black `#030A15` — حذف رنگ‌های بی‌ربط؛ error/warning از دیفالت MUI.
- [x] **یکدست‌سازی نام برند:** BaziG3 → BaziGB (۵ مورد).
- [x] **لوگوی رسمی:** استفاده از لوگوی ترنسپرنت در هدر، hero، auth، فوتر و favicon (شفافیت بازیابی شد).

## فاز ۴.۵ — بدهی‌های فنی (بچ ۱۵-ب — تکمیل شده ✅)
- [x] **تغییر رمز کاربران:** `PATCH /auth/change-password` + کارت UI در پروفایل (بچ ۱۵-ب).
- [x] **هویت سوکت با JWT:** اتصال socketId ↔ userId در handshake (بچ ۱۵-ب).
- [x] **تایمر نوبت:** ۱۲۰ ثانیه per-room با end-turn خودکار برای تخته‌نرد/وگاس (بچ ۱۵-ب).
- [x] **Admin Panel (تکمیل):** تغییر نقش کاربر (USER↔ADMIN با تأیید، self-demotion مسدود) + آمار عمیق‌تر (کاربران جدید، بازی‌های امروز/هفته) — بچ ۱۵-ب.
