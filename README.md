# BaziGB - پلتفرم بازی‌های رومیزی آنلاین

**BaziGB** یک پلتفرم مدرن، ماژولار و دیتابیس‌محور برای بازی‌های رومیزی آنلاین است که با تمرکز بر توسعه‌پذیری و پرفورمنس طراحی شده است.

## وضعیت پروژه: بچ ۲ تکمیل شد ✅
پروژه اکنون دارای زیرساخت کامل دیتابیس (Prisma) و سیستم احراز هویت (JWT) در سمت سرور است و بازی دوز به صورت چندنفره و پایدار قابل اجراست.

## قابلیت‌های کلیدی
- **انجین بازی اختصاصی:** مدیریت نوبت‌ها و وضعیت بازی به صورت متمرکز.
- **معماری پلاگین‌محور:** اضافه کردن بازی‌های جدید بدون دست زدن به کدهای هسته.
- **ارتباط زنده (Real-time):** استفاده از Socket.io برای همگام‌سازی لحظه‌ای بازیکنان.
- **پایداری (Persistence):** ذخیره دائم اطلاعات کاربران، اتاق‌ها و تاریخچه مسابقات در دیتابیس.
- **احراز هویت امن:** استفاده از JWT و هش کردن پسوردها با Bcrypt.

## ساختار پروژه
این پروژه به صورت یک **Monorepo** مدیریت می‌شود:
- **`apps/web`**: رابط کاربری (Next.js + TailwindCSS).
- **`apps/server`**: سرویس‌های بک‌اِند (NestJS + Prisma).
- **`packages/engine`**: هسته منطق بازی‌ها.
- **`packages/games`**: پکیج‌های اختصاصی بازی‌ها (دوز، و در آینده شطرنج و غیره).

## نحوه اجرا و توسعه
۱. نصب تمام وابستگی‌ها:
```bash
npm install
```

۲. تنظیم دیتابیس (Prisma):
در پوشه `apps/server` فایل `.env` را چک کرده و سپس:
```bash
npx prisma generate
```

۳. اجرای پروژه‌ها:
```bash
# فرانت‌اِند
npm run dev:web

# سرور
npm run dev:server
```
