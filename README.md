# BaziGB - پلتفرم بازی‌های رومیزی آنلاین

**BaziGB** یک پلتفرم مدرن و ماژولار برای بازی‌های رومیزی آنلاین است که با تمرکز بر توسعه‌پذیری و پرفورمنس طراحی شده است.

## ساختار پروژه

این پروژه به صورت یک **Monorepo** مدیریت می‌شود:

- **`apps/web`**: رابط کاربری اصلی ساخته شده با Next.js و TailwindCSS.
- **`apps/server`**: سرور اصلی برای مدیریت ارتباطات زنده (WebSocket) و دیتابیس با NestJS.
- **`packages/engine`**: هسته منطق بازی‌ها که مدیریت نوبت‌ها و وضعیت را بر عهده دارد.
- **`packages/games`**: پکیج‌های اختصاصی هر بازی (مانند شطرنج، دوز و ...).

## نحوه توسعه

برای نصب وابستگی‌ها در تمام پکیج‌ها:
```bash
npm install
```

اجرای فرانت‌اِند:
```bash
npm run dev:web
```

اجرای سرور:
```bash
npm run dev:server
```

## هدف
هدف ما این است که هر بازی جدید را به صورت یک پلاگین ساده به سیستم اضافه کنیم، بدون اینکه نیازی به تغییر در کدهای اصلی انجین یا سرور باشد.
